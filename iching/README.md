# 周易 · 蓍草占筮

以朱熹《筮仪》为依据的中文静态占筮网页。使用原生 HTML、CSS、JavaScript，无构建步骤或第三方运行依赖，可直接由本仓库的 GitHub Pages 在 `/iching/` 路径提供访问。

## 本地使用

在仓库根目录运行（需要现代版本 Node.js）：

```sh
node iching/serve.mjs
```

浏览器打开 <http://127.0.0.1:4173/iching/>。预览服务仅监听本机，只提供 `iching` 文件夹内容；可通过 `PORT` 环境变量修改端口。浏览器需通过 HTTP 或 HTTPS 访问，不建议直接双击 HTML 文件。

运行验证：

```sh
node --test iching/tests/*.test.mjs
```

导出完整卦记后，可在本机复算：

```sh
node iching/verify.mjs "导出的卦记.json"
```

复核器校验记录版本、算法模型、随机数格式与拒绝采样，并逐项比较六爻十八变和消耗计数。成功退出码为 `0`，不一致为 `1`，文件或 JSON 错误为 `2`。结果只说明记录内部计算一致，不能证明随机来源或记录时间；未使用的随机数也无法由演算结果验证。

填写所问之事、选择随机源后起卦。每爻三变，六爻共十八变，自下而上成卦；结果展示本卦、变爻、之卦与可复核的演算过程。

## 经文与传文

六十四卦均收录卦辞、六爻爻辞、完整《彖传》与《象传》。《象传》区分说明全卦的大象与逐爻对应的小象；乾、坤还收录用九、用六及其对应小象。文本来自各卦所附的维基文库《周易》原文链接，采用简体字形，保留古籍异文，不加入现代译释。

起卦结果中的本卦和之卦均展示卦辞、彖传与大象；动爻下面附对应小象，展开六爻可通读本卦全部爻辞与小象。卦典也提供完整经传。已收藏的卦记在重读时自动使用这些新增经文。

## 蓍草算法

依据[《原本周易本义》卷末下·筮仪](https://zh.wikisource.org/zh-hans/原本周易本義_(四庫全書本)/卷末下)：五十策取一不用，每爻从四十九策开始；每变分二、右取一策为挂一、左右各以四计数，余数为一至四，整除时留四。除去挂一与两边余策，三变后以余策除以四，得到六、七、八、九。

程序将左堆的四种余数视为等可能，再从该余数对应的合法分堆中等概率选取分堆；右堆在挂一后仍须有策。这一建模对应原文一变三奇一偶、后两变奇偶各半，老阴、少阳、少阴、老阳的概率分别为 `1/16、5/16、7/16、3/16`。**这不是所有分堆大小等概率的模型，也不声称重现真实手分蓍草的物理概率。** 每一步均保留实际左右策数与去留策数。

## 随机源与记录

- **RANDOM.ORG 公共接口（默认）**：无需 API Key，以大气噪声提供随机数。官方已将此 HTTP 接口列为旧接口；可用性、IP 额度、网络和浏览器跨域策略均可能影响访问。[官方说明](https://www.random.org/clients/http/)
- **RANDOM.ORG JSON-RPC API**：可填写自己的 API Key 使用现代接口。Key 仅用于当前页面会话并直接发送给 RANDOM.ORG，不进入本地记录或导出文件。静态网页不内置共享密钥。[API 文档](https://api.random.org/json-rpc/4/basic)
- **Web Crypto**：用户可主动选择浏览器的 `crypto.getRandomValues()`。无需请求外部随机服务；它是浏览器提供的密码学随机源，不宣称为大气噪声或独立物理随机源。

各来源的整数均通过拒绝采样映射到所需范围，避免取模偏差。全站不使用 `Math.random()`，外部服务失败时明确报错，**不会静默切换随机源**。重新起卦会重新获取随机数。

问事内容在浏览器内处理，不发送给随机服务；随机服务仍会接收到请求者的 IP 等网络信息。只有主动开启保存功能后，记录才写入当前浏览器的本地存储。JSON 导出包含随机源信息、原始随机整数和十八变过程，可用于复算；它不带 RANDOM.ORG 数字签名，不是第三方认证凭证。导出的问事内容请自行保管。

网页用于传统文化体验与个人思考。卦辞与爻辞提供阅读材料；《筮仪》本身并未给出一套完整的多爻变断语规则，网页不将自行编造的规则归于原文。

本次实现仅写入工作区，未执行 Git 提交、推送或部署。
