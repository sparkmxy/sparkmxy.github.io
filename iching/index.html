02 /

古法，今筮

读《筮仪》原文 ↗
一

分而为二

五十茎蓍草，取一不用。将余下四十九茎分作左右两束，以象两仪。

二

挂一揲四

从右束取一茎，称为「挂一」。左右两束各以四茎为组，数出余数。

三

归奇于扐

整除时以四为余。合起挂一与两束余蓍，置于一旁，即成一变。

四

三变成爻

余蓍再行两变，除以四得六、七、八、九。每爻重取四十九蓍，自下而上成卦。

关于随机性与数字化筮法 ＋

《筮仪》记述首变奇偶为三比一，后两变奇偶各半。此页每变先等概率选择左束除四的余数（一至四），再从满足该余数的合法分束中等概率取一组，完整演算挂一与归奇。它是依原文比例构造的数字模型，不是假定所有分束位置等概率。所得老阴、少阳、少阴、老阳概率分别为 1/16、5/16、7/16、3/16。

本机模式使用 Web Crypto 的 crypto.getRandomValues，由浏览器提供密码学安全随机数；它不等同于可独立验证的物理真随机。RANDOM.ORG 模式连接其大气噪声随机服务。公共免密钥接口为官方旧版 HTTP 接口，新版 JSON-RPC 需自备 API Key。各来源均以拒绝采样避免取模偏差，连接失败会明确报错，不自动更换随机源。

可导出本次原始随机数和十八变记录以复算。记录用于检查计算过程，不构成第三方签名证明。解读区提供本卦、之卦的卦辞、彖传与大象，以及动爻的爻辞和小象，供参读与自省。
